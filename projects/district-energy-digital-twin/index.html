District energy
digital twin.

A sanitized overview of my controls internship work: process simulation, operator-interface development, and control-strategy validation for a multi-building district-energy system.

ORGANIZATIONCreative EnergyMY ROLESystems Engineering InternTIMEFRAMESeptember–December 2024

CONTEXT

Test the control design before the plant is live.

A process simulator and digital twin can give engineers a place to check operating sequences, tune control loops, and support operator training before commissioning. My work focused on translating process behavior and control intent into a usable DeltaV simulation and operator interface.

MY CONTRIBUTION

Model behavior, then check it against intent.

  • Built DeltaV composite simulation modules for equipment such as heat exchangers, pumps, valves, and energy-transfer stations, representing flow, pressure, and temperature behavior.
  • Designed a four-level operator HMI in DeltaV Live, following ISA-101 hierarchy and developing reusable graphics for equipment classes.
  • Reviewed the control narrative against the implementation to identify discrepancies and support design changes.
  • Supported PID tuning and closed-loop validation of control strategies.

RESULT

Use simulation to catch a design issue early.

Simulation exposed a high-pressure circulation-pump issue associated with chiller recirculation. A variable-speed change was implemented to address the inefficiency before physical commissioning.

Control design flaw found before commissioning

The simulation informed a variable-speed adjustment; this public case study omits client-identifying system details and internal control artifacts.

WHAT I LEARNED

The model is useful when it answers an operator’s question.

Simulation fidelity, control intent, and HMI hierarchy have to work together. The operator interface provides the context to understand system state; the model provides a safe environment to exercise the control logic and refine it.
