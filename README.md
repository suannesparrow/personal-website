# Suanne Sparrow — Engineering Portfolio

A responsive, static engineering portfolio built with HTML, CSS, and a small amount of JavaScript. It is designed for GitHub Pages and does not require a build step.

## Pages

- `index.html` — selected projects, experience, education, skills, and contact
- `projects/wind-turbine-monitoring/` — embedded sensing, FreeRTOS acquisition, networking, and validation
- `projects/district-energy-digital-twin/` — sanitized controls and simulation case study
- `projects/macbook-chassis/` — fixture, CAM, DFM, and process verification
- `projects/rc-vehicle/` — composite materials, vehicle redesign, and manufacturing planning
- `projects/strain-gauge-scale/` — analog signal conditioning and MATLAB data acquisition

## Run locally

Open `index.html` in a browser, or serve the repository root with any static HTTP server. The Google Fonts link is optional; system fonts are used as fallbacks.

## Publishing

The repository is connected as `origin`. To publish with GitHub Pages, select the `main` branch and repository root under **Settings → Pages**. Add a custom domain later if desired.

## Public-content notes

- No phone number or student email is included. Contact currently links to the public GitHub profile; add a preferred public email or LinkedIn URL if desired.
- The district-energy case study intentionally omits client-identifying details, plant-specific data, internal HMI screenshots, and control diagrams.
- The RC vehicle page uses a clearly labeled illustration rather than implying a project photo or CAD render. Add original approved evidence when available.
- Images are stored locally in `assets/` and have descriptive alternative text where they convey project information.
